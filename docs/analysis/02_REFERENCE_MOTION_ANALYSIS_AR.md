# تحليل المرجعين (فريم بفريم)

## المرجع أ — فيديو "how do you communicate…" (768×576، 24 ث)
تسلسل المشاهد المرصود:
1. **افتتاح بصفحة صفراء** + كلمة واحدة كبيرة ثم تحويل لورقة بيضاء بحركة قلم (wipe بحبر أسود).
2. **الجملة تُكتب كلمة بكلمة** على خلفية رمادية فاتحة (typewriter) مع صغر خط ثابت وموضع ثابت — النص هو البطل.
3. **عناصر بيكسل-آرت تتطاير** حول الجملة (عملة، كاميرا، كلاكيت) مع خطوط حركة (motion streaks) ثم blur.
4. **توهج أزرق جانبي (lens flare)** يتحرك عبر الإطار ثم **قطع حاد لأسود** مع صورة شخص (silhouette) برتقالي متوهج: تغيّر كامل في لوحة الألوان = إحساس انتقال قوي.
5. الكلمات تتبدل في نفس المكان (you → you dont → you just show) = **استبدال لا إضافة**.
6. **حلقة أيقونات بيكسل** تدور حول مركز، ثم **ضربة مسح قطري** (sweep) تقودنا لمشهد جديد.
7. **نجمة حمراء** تكبر وتبتلع الإطار (star-wipe) والكاميرا تقترب من الكاميرا الرمزية.

**القواعد المستخلصة:** لوحة لونية واحدة لكل مشهد؛ كل انتقال يحمل عنصراً من المشهد التالي (match-cut)؛ النص دائماً قصير ومتغير في نفس الموضع؛ حركة ثانوية دائماً (جزيئات/خطوط) حتى في الثبات.

## المرجع ب — Motion Smith (1280×720، دقيقتان)
أنماط متكررة:
- **شخصية بيكسل ثابتة (محقق بقبعة) + رفيق برتقالي صغير** تعيش داخل بيئة ثلاثية الأبعاد (مكتب، مكتبة، غرفة حمراء) — الشخصية **لا تتغير** عبر الفيديو (استمرارية).
- **كاميرا 3D حقيقية**: دوران حول المكتب، تقريب نحو الشاشة، ثم الدخول في الشاشة ينقلنا لمشهد جديد (**zoom-through transition**).
- **نص حركي ضخم** بخطوط مختلفة (ثقيل/خفيف/مائل) وألوان تأكيد (أحمر/أبيض) داخل البيئة وأحياناً **خلف** العناصر.
- كلمة التأكيد تكبر وتُرسم بلون مختلف: "WRONG" "SLOP" "NEVER" "BETTER".
- مشاهد كونية (قمر، شمس) كـ**استعارة**، تُستخدم كفاصل بين أفكار.
- **بكسلة (pixelate dissolve)** كانتقال: مربعات برتقالية/حمراء تكبر وتغطي الإطار.
- إضاءة دافئة + bloom خفيف + vignette ثابت على كل المشاهد.

## الفرق الجوهري عن تطبيقنا
| المرجع | تطبيقنا الآن |
|---|---|
| المشهد مليء ببيئة + شخصية + نص + جزيئات | خلفية سوداء + كلمة + عنصر واحد |
| الكاميرا تقود الانتقال | قص مباشر ثم crossfade |
| الشخصية ثابتة ومعروفة | مربع برتقالي عشوائي لكل مشهد |
| نص بأحجام وأنماط متعددة | نمط واحد bold_center |
